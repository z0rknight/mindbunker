How RMEDIA OS moves.

Animation follows truth: a state changes on screen only after the canonical action succeeds. Every scene has a static, non-motion form, a reset, and a trigger. Nothing here calls an API or writes anything; “server” results are simulated by the controls above. All data is fake.

16 · Action states & save feedback

Answers: did it work? Loading appears only if the action takes >150ms and then stays ≥300ms (no 50ms flicker). Success appears closest to the changed thing: inline text, a state dot, a border tint, or a row tint — chosen by object, not by mood.

idle → hover → pressed → loading (after 150ms) → success | error → idle
